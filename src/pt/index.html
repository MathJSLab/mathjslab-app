Este é um aplicativo de demonstração do pacote npm MathJSLab (repositório), um emulador de um subconjunto da linguagem MATLAB®/Octave escrito completamente em TypeScript. Este aplicativo é destinado a fins educacionais. Consulte as notas abaixo para obter informações detalhadas.
