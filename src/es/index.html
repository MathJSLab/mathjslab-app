Esta es una aplicación de demostración del paquete npm MathJSLab (repositorio), un emulador de un subconjunto del lenguaje MATLAB®/Octave escrito completamente en TypeScript. Esta aplicación está destinada a fines educativos. Consulte las notas a continuación para obtener información detallada.
