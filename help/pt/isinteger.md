- `TF = isinteger (X)`

Retorna verdadeiro se `X` é um objeto inteiro.

Objetos inteiros incluem classes como `int8`, `uint8`, `int16`, `uint16`,
`int32`, `uint32`, `int64` e `uint64`.

Constantes numéricas geralmente são valores de ponto flutuante de dupla
precisão, portanto `isinteger (14)` é falso a menos que `14` tenha sido
convertido explicitamente para uma classe inteira.

Veja também: `isfloat`, `ischar`, `islogical`, `isnumeric`, `isa`.
