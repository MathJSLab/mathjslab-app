- `Y = double (X)`

Converte `X` para forma de ponto flutuante de dupla precisão.

Para entrada numérica, retorna valores representados como números de dupla
precisão. Para entrada lógica e de caracteres, retorna os valores numéricos
correspondentes em dupla precisão.

Veja também: `single`, `char`, `logical`.
