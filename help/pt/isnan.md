- `TF = isnan (X)`

Retorna um array lógico que é verdadeiro onde os elementos de `X` são valores
`NaN`.

Elementos que não são `NaN` retornam falso. No Octave, valores numéricos
ausentes como `NA` também são considerados valores `NaN`.

Veja também: `isinf`, `isfinite`.
